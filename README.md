# Ruturaj Kumbhar — Portfolio Website

Plain HTML + CSS + JavaScript. No build step, no installs.

## Files
- `index.html` — page content (edit text here)
- `style.css` — colors and layout (colors are at the top, in `:root`)
- `script.js` — skills list, animations, theme toggle, contact form
- `assets/profile.jpg` — your photo
- `assets/Ruturaj_Kumbhar_Resume.pdf` — the Resume button downloads this

## Host on Netlify (easiest)
1. Go to https://app.netlify.com/drop and sign up (free).
2. Drag the whole `portfolio` folder onto the page.
3. Your site is live at `something.netlify.app`. Rename it under Site settings > Change site name.
4. The contact form works automatically on Netlify (messages appear under Forms).

## Host on GitHub Pages
1. Create a GitHub repository named `<your-username>.github.io`.
2. Upload all the files (keep the `assets` folder).
3. Repository Settings > Pages > Source: "Deploy from a branch" > `main` / root > Save.
4. Live at `https://<your-username>.github.io` in a minute or two.
5. Note: on GitHub Pages the contact form opens the visitor's email app instead.

## To check before publishing
- GitHub link: the resume shows `github.com/Ruturaj_Kumbhar`, but GitHub usernames cannot contain underscores. Search `index.html` for `github.com/` and put your real username.
- To update the resume, replace the PDF in `assets/` with the same file name.
